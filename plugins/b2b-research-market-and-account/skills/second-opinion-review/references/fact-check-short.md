# Short fact check (carried inside this skill so it stands alone)

Use it for filter 1 on every point that rests on a fact, and on every fact in the final version.

1. List the factual claims in the critique and in the draft. scripts/claims_scan.py lists sentences with numbers, dates, superlatives, attributions and quotes, and checks weekdays and dashes. Report its list as printed: it gives each sentence's types, not the word that matched, so never say which word or reason made it flag a line.
2. Open the source for each claim in this session (in Manual mode, including when the user asks to work only from what they shared, nothing outside the shared material is opened or searched; such a point is "as pasted, not yet checked" or "not checked in this session", with the labels of item 5): the source the user named first; then primary sources (filings, the publisher's own report, the product's own documentation, regulators); then the subject's own site, written as the subject's statement; then publications that name their source.
3. Match the claim to the source exactly: the figure, its label (revenue is not revenue from operations; detections are not attacks), its base, its period, and the date of the source.
4. Write the claim only as strong as its source: past tense for old figures, "the company describes itself as" for a company's own superlative, "about 3 in 10" rather than "1 in 3" for 29.5 percent.
5. If the source cannot be opened, run a web search for the claim's wording; text from the results is labelled "from a search result; the page itself was not opened", and the point is "not checked in this session" and is not applied as fact. If the only source is text the user pasted or attached, the point is "as pasted, not yet checked": it may be applied at the strength of the paste, and is never called verified.
6. Check every date's weekday and that a current document does not carry last year's date.
7. Never write "verified", "all checked" or "accurate" without the source and its quote shown.
